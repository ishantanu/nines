# SLO practices plan

This plan turns recommended SLO practices into independently testable capabilities. Each item keeps Nines' rules: measurements are deterministic, missing data stays unknown, and saved definitions, deployed rules, backend evaluation and observed SLI remain separate.

Planned capabilities are not available yet. The status column is the source of truth.

## Rules for every chunk

- Define exact semantics before the interface, and keep the CLI, API, Go client and portal consistent.
- State limitations in the response, not only in the documentation.
- Never present an approximation as a measurement. A bound, a heuristic and a measured value are labelled differently.
- Keep opt-in anything that adds cost or exposes customer-level data.
