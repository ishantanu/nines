Nines incorporates scoped adaptations of the free theme palette and the
Sparkline, Donut Chart and Bar Chart components (v1.0.0).
Component sources: https://beautiful-ui.dev/r/sparkline.json
https://beautiful-ui.dev/r/donut-chart.json
https://beautiful-ui.dev/r/bar-chart.json
No Beautiful UI Pro component source is incorporated.

Additional scoped adaptations: Animated Counter, Metric Card, Badge, Sign In,
Text Shimmer and Text Reveal (v1.0.0), from the free registry items:
https://beautiful-ui.dev/r/radix-nova/animated-counter.json
https://beautiful-ui.dev/r/radix-nova/metric-card.json
https://beautiful-ui.dev/r/radix-nova/badge.json
https://beautiful-ui.dev/r/radix-nova/sign-in.json
https://beautiful-ui.dev/r/text-shimmer.json
https://beautiful-ui.dev/r/text-reveal.json
Nines retains existing authentication and uses compact, accessible adaptations.
No Beautiful UI Device Login block or Pro source is incorporated.

The Sign In block is now vendored at components/ui/notchset/blocks/sign-in.tsx,
with its free Input OTP, Segmented Control, field/button classes and scoped
instrument helpers. Nines adds an account-form slot and disables passwordless
and signup controls in the shipped adapter. The original source is preserved
with these local modifications; audio is disabled by the root attributes.
Dependency component sources:
https://beautiful-ui.dev/r/radix-nova/input-otp.json
https://beautiful-ui.dev/r/radix-nova/segmented-control.json

Dependency: input-otp 1.5.0 (https://github.com/guilhermerodz/input-otp)

The public homepage incorporates the actual free Feature Bento v1.0.0 block,
with Nines illustration content, generic burn-rate formatting, guide links,
accessible chart controls and pause/visibility/reduced-motion handling.
Source: https://beautiful-ui.dev/r/radix-nova/feature-bento.json
Its silent showcase helpers do not load the portal authentication or audio code.

The SLO Metric Card frame in components/ui/notchset/blocks/metric-card.tsx is adapted from https://beautiful-ui.dev/r/radix-nova/metric-card.json (Metric Card v1.0.0). Exact measured values and existing gap-aware SLI history replace rolling digits, generic deltas and sample series.
